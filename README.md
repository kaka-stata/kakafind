## 这是什么

做实证研究时，变量怎么测量散落在各篇论文的"变量选择"小节里，很难检索。这个库把已读文献里每个核心变量的测度方法整理成可检索的条目：

- **测度大类与口径**：同一个概念（比如融资约束）有哪几种主流测法（SA 指数、KZ 指数、WW 指数等），每种测法的口径区别是什么。
- **完整计算说明与公式**：数据来源、构造步骤、后续处理（取对数、缩尾、滞后等）和 LaTeX 公式。
- **数值解读**：这个指标越大代表什么。
- **机制命名**：作者把这个变量包装成什么影响机制，不同论文的不同叫法都保留。
- **原文引句和出处**：每条记录附原文逐字引句、页码和论文信息，同一种做法最多列 3 篇，期刊级别高、发表时间新的优先。
- **控制变量**：常用控制变量的定义和参考文献单独成页。
- **引用包**：把选中的测度和出处收集起来，方便写方案时引用。

## 怎么用

1. 打开网址，在顶部搜索框输入指标名（如"融资约束""企业规模""数字化转型"）。
2. 左侧是结果列表，也可以按研究大类、二级分类的菜单浏览。
3. 点开一个概念，右侧看它的各种测度大类、计算说明、公式和参考文献。
4. 搜"DID""试点"可以看到政策冲击变量，这类变量单独成类。

## 怎么保证不是模型瞎编

- **无证据不入库**：每条记录必须带一句原文引句，程序会逐字回到论文全文里核对，找不到的一律丢弃，不靠模型记忆补充。
- **公式与数字核对**：计算说明里出现的数字，必须在原文引句或上下文里出现过，否则回退到原文简述。
- **只收明确识别的期刊**：论文的期刊必须能从页眉或目录里确认，识别不了的不收。

## 使用提示

- 概念归并、分类、口径合并是程序和 AI 共同完成的，没有逐条人工核对，个别条目可能分类不准或口径合并过粗，用于文献检索和写方案参考，**正式引用请回到原文核对**。
- 引句只用于说明测度方法的出处，版权属于原论文作者和期刊。如果你是作者，认为某条内容不适合公开，请在本仓库的 Issues 里留言，我会处理。
- 控制变量页只覆盖部分论文，不代表全部文献。
- 页面里的公式用浏览器自带的数学排版显示；如果打开页面时电脑没联网，公式会显示为源码文本，其余功能不受影响。
